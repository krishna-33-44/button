# 🔊 FAAHH Glassmorphism Button

A sleek, responsive web app featuring an Apple-inspired liquid glassmorphic button centered on a true OLED black background with ambient glowing accents. Built with pure HTML, CSS, and vanilla JavaScript.

---

## ✨ Features

* **Absolute Centering:** Perfectly aligned horizontally and vertically using CSS Flexbox layout.
* **Apple OLED True Black:** Designed with `#000000` dark background for maximum contrast.
* **Frosted Glassmorphism:** Uses modern CSS `backdrop-filter` and soft ambient glows to emulate VisionOS/macOS translucent UI elements.
* **Audio Playback:** Plays a custom sound clip on click/tap with instant spam-replay functionality via vanilla JavaScript.
* **Mobile-Optimized:** Built with liquid button tap scaling and fluid layout support for all mobile viewports.
